Fiber v2 vs v3 benchmarks

In-process request benchmarks. Both versions run interleaved on the same CI machine, each with its own API and dependencies.

Reading the numbers

  • Each bar is the change of the v3 median against the v2 median over all runs of a snapshot. Thin gray bars and ~ mean benchstat found no significant difference (p ≥ 0.05).
  • Time covers request setup and the handler. App construction, response serialization and the network are not included.
  • Compare versions within one snapshot. CI machines differ between snapshots, so absolute numbers do not carry over.
  • fasthttp_floor runs no Fiber code and shows what the fasthttp upgrade alone changes.
